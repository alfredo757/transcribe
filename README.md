# Transcribe

Transcribe 1.6.1 is a progressive web app that records, transcribes, and answers questions about notes on this device.

https://alfredo757.github.io/transcribe/

## Add to iPhone Home Screen

1. Open the site in Safari.
2. Tap Share.
3. Tap Add to Home Screen.

## Phone and PC

Recording, on-device transcription, and questions about notes stored on the phone run without a PC.

Video links and the larger vision model need the PC at https://ph-321-s2.tail94b785.ts.net.
